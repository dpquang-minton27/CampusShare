# CampusShare

Ứng dụng Android hỗ trợ sinh viên trong cùng trường đăng tin cho tặng hoặc trao đổi đồ dùng còn sử dụng được. Đây là đồ án môn **Lập trình trên điện thoại di động** của nhóm 3 sinh viên.

## Chức năng dự kiến

- Đăng ký, đăng nhập và quản lý hồ sơ.
- Đăng tin có hình ảnh; sửa, xóa và cập nhật trạng thái bài đăng.
- Tìm kiếm theo tên, lọc danh mục và hình thức cho tặng/trao đổi.
- Lưu bài đăng yêu thích.
- Gửi yêu cầu nhận/trao đổi; người đăng chấp nhận, từ chối và đánh dấu hoàn tất.

Phiên bản đầu không bao gồm thanh toán, giao hàng, bản đồ hoặc chat thời gian thực.

## Công nghệ dự kiến

Kotlin, Android Studio, giao diện XML, Firebase Authentication, Cloud Firestore và Cloud Storage for Firebase. Thiết kế màn hình bằng Figma; quản lý tiến độ bằng Trello. Các lựa chọn kỹ thuật sẽ được chốt trong giai đoạn thiết kế.

## Trạng thái repository

Repository hiện được khởi tạo với README và .gitignore cho Android. **Mã nguồn ứng dụng chưa được đẩy lên.** Khi có project Android Studio, nhóm sẽ đưa mã nguồn vào repository này và cập nhật hướng dẫn cài đặt/chạy ứng dụng.
